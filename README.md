# OrnaFlow — Cloud Web Prototype

Responsive inventory and credit-sales prototype for Windows and Android browsers.

## Hosting
GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Expected URL: https://zense-lk.github.io/ornaflow-web/

## Backend
Supabase project: `infemulsjggtozskmeuh`. Only the **publishable** browser key is included. Never commit a database password, service-role key, or customer exports.

## Usage
Open the website and use Cloud setup to sign up, confirm your email if required, then create your business workspace. Cloud-mode entries are shared through the database. Demo mode uses local browser data.

**Pilot build only:** Do not use for actual inventory, accounting, or payments until authentication, stock and credit-sale workflows, data recovery, and invoice compliance have been tested end-to-end.
